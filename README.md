# InvestUG T-Bond Calculator

This is a static HTML/JavaScript calculator for Ugandan Treasury Bonds (T-Bonds), designed to estimate returns, taxes, and earnings.

## How to Deploy (Netlify Example)

1. Create a free account at [Netlify](https://www.netlify.com/)
2. Upload the contents of this folder (especially `index.html`)
3. Netlify will generate a live URL you can embed in your Durable site using an iframe.
